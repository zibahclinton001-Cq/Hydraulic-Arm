# Hydraulic Arm Robot 

Industrial robot arm simulation built 100% on Android phone.

Problem
Factory tasks like picking and dropping are risky for humans.

 Solution
Autonomous arm with 3 degrees of freedom:
- Shoulder rotation
- Elbow movement
- Gripper open/close

Demo
Picks bottle -> Moves -> Drops in bin
Simulates real hydraulic pressure logic.

Tech
Python | OOP | Robotics Kinematics Basics

 Future
Connect to Arduino + servo motors + syringe hydraulics.
